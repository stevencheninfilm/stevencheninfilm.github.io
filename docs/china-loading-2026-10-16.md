# 首屏加载优化 · 2026-10-16

首页和 index-v3 共用相同 HTML，默认展示内容及导航，开场不再依赖脚本来解除隐藏。首页脚本全部 defer，目标页仍保留原有提前执行的共享转场以兼容到达动画。

开场素材失败、等待超过 700ms、脚本超过 1.8 秒才到达、节流到 2G 或用户开启省流量时，直接显示首页；快速加载仍保留原图片墙。Skip intro 在触屏上可见。未选中的六个项目大图、标志、响应式来源按切换/横向浏览可见范围加载，所有次级图片一起恢复，避免 logo 漏载。已有视频按需加载逻辑保持不变。

本地 HTML 直接引用资源预算（去重、排除 data-src 延后视频和 CSS 背景资源，非实际 HAR 流量）：8,337,996 → 1,383,063 字节，减少 83.4%。并非整站总大小，也不承诺大陆网络下具体秒数。

Node 测试 121 项全部通过，覆盖慢图跳过、失败恢复、迟到脚本、省流量、无脚本可见导航、多图片和响应式来源按选择加载、现有作品/转场/玄天内容。未启动另一个预览服务。浏览器来源授权限制下没有冒充完成本版视觉验收。

主站和游戏目前都走 GitHub Pages。同域名 CDN 可共用，需先确认沪ICP备2021013583号-1 当前仍有效（2026-05-13 历史订单为取消阿里云接入），再核对费用、HTTPS、Host/SNI、缓存及 DNS 回退。此次代码提交没有改 DNS 或开通资源。
