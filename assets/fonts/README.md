# Xuantian Jue heading font

`xuantian-headings-500.woff2` is a Noto Serif SC Medium (500) subset served by
Google Fonts. It contains the Chinese characters used in this project's display
headings; body text and English use the system sans-serif stack.

The font is self-hosted so the page does not depend on a third-party font request.
If Chinese headings change, regenerate the subset with the updated heading text.
Missing glyphs fall back to the visitor's local Songti/serif font.

`xuantian-jue-8bc0-500.woff2` adds U+8BC0 (诀) for the project name 玄天诀.
It is the same Noto Serif SC Medium, fetched from the official Google Fonts CSS
API using `family=Noto+Serif+SC:wght@500&text=诀&display=swap` (v35).
Both subsets remain self-hosted under the same OFL license.

Source: https://fonts.google.com/noto/specimen/Noto+Serif+SC
